# 企灵 Agent 产品愿景

## 产品名

企灵 Agent

## 产品定位

企灵 Agent 是面向企业微信私域销售团队的自动跟进与复盘 Agent。

它不是一个需要销售主动提问的 AI 聊天工具，而是一个会主动分析客户状态、生成待确认话术、沉淀客户画像、统计销售过程并输出复盘建议的销售执行系统。

## 一句话介绍

企灵 Agent 自动识别客户机会、生成销售话术并创建待确认跟进任务，让销售只需确认关键动作。

## 核心闭环

```text
企业微信或上传聊天记录
-> Agent 自动分析客户上下文
-> 自动生成客户画像和意向判断
-> 自动生成下一步跟进话术
-> 销售确认后复制发送
-> 系统记录采纳和反馈
-> Agent 自动统计、复盘并提出改进建议
```

## 第一版目标用户

### 一线销售

每天需要跟进大量企业微信客户，希望系统自动告诉自己：

- 今天该跟谁。
- 为什么要跟。
- 发什么更合适。
- 哪些客户有机会。
- 哪些客户有流失风险。

### 销售主管

需要快速了解团队客户质量和执行情况，希望系统自动给出：

- 高意向客户列表。
- 长时间未跟进客户。
- 销售跟进问题。
- 话术效果。
- 改进建议。
- 需要主管介入的客户。

## 第一版数据入口

### 主入口：企业微信

目标能力：

- 同步企业微信客户。
- 同步客户标签。
- 同步外部联系人资料。
- 同步或导入聊天记录，具体取决于企业微信权限和消息存档能力。

### 补充入口：上传或粘贴聊天记录

支持：

- 粘贴聊天文本。
- 上传 `.txt`、`.csv`、`.xlsx`、`.docx` 等聊天记录文件。
- 解析客户、销售、时间和消息内容。
- 用于企业微信接口未完全打通时验证 Agent 核心能力。

## 第一版核心能力

### 自动客户画像

根据资料、标签和聊天记录生成：

- 需求点
- 预算倾向
- 产品兴趣
- 主要顾虑
- 沟通风格
- 当前阶段
- 意向等级
- 推荐策略

### 自动话术生成

根据客户上下文生成可复制话术：

- 破冰话术
- 需求挖掘话术
- 产品介绍话术
- 价格异议话术
- 案例证明话术
- 促单话术
- 沉默唤醒话术
- 复购和转介绍话术
- 投诉安抚话术

### 待确认跟进任务

Agent 自动创建任务：

- 客户是谁。
- 为什么要跟进。
- 推荐什么时候跟。
- 推荐发送什么。
- 有什么风险。
- 销售可以复制、修改、换一种、跳过或标记不准。

### 自动统计

系统自动统计：

- 客户总数
- 高意向客户数
- 今日待跟进客户数
- 超时未跟进客户数
- 沉默客户数
- 异议客户数
- 话术采纳率
- 客户回复率
- 阶段推进率
- 成交转化率
- 流失风险客户数

### 销售复盘

Agent 自动输出：

- 今日客户机会。
- 哪些客户最值得优先跟。
- 哪些客户已经有流失风险。
- 哪类问题客户问得最多。
- 哪些话术客户回复更好。
- 哪些跟进动作推进了成交。
- 哪些客户需要主管介入。
- 明天建议优先做什么。

### 改进建议

Agent 给出可执行建议：

- 建议补充某类案例素材。
- 建议调整价格解释话术。
- 建议缩短首次响应时间。
- 建议对高意向客户增加预约动作。
- 建议对沉默客户改用轻量唤醒。
- 建议主管复盘某几个低回复客户。

## 第一版发送方式

第一版采用复制发送：

```text
Agent 生成话术 -> 销售确认 -> 一键复制 -> 销售粘贴到企业微信发送
```

暂不直接自动发送客户消息。后续可以在稳定后支持企业微信侧边栏确认发送或后台接口发送。

## 风险边界

以下内容必须人工确认：

- 价格承诺
- 优惠政策
- 合同条款
- 退款相关
- 投诉处理
- 医疗、金融、法律等敏感行业内容
- 任何可能影响客户信任的确定性承诺

## 第一版页面

```text
工作台
客户列表
客户详情
待确认话术
复盘中心
数据接入
系统设置
```

## 非目标

第一版不做：

- 完全自动发送。
- 替代完整 CRM。
- 复杂多部门流程编排。
- 全行业通用办公 Agent。
- 大规模多 Agent 平台。

## 成功标准

第一版成功标准：

- 销售能通过上传聊天记录或企业微信数据获得可用话术。
- 销售每天能看到明确的待确认跟进任务。
- 客户画像和意向判断能解释来源和理由。
- 复盘中心能指出具体客户机会、风险和改进建议。
- 主管能看出哪些客户值得跟、哪些销售动作需要调整。
