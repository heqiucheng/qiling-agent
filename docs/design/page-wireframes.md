# 企灵 Agent 页面线框设计

**状态**：Draft for frontend architecture  
**版本**：v0.1  
**日期**：2026-05-28  
**依赖文档**：`docs/specs/mvp-prd.md`、`docs/design/ui-design-system.md`

## 1. 设计目标

页面设计必须围绕第一版核心闭环：

```text
导入客户/聊天记录
-> Agent 自动分析
-> 生成待确认话术
-> 销售复制发送
-> 系统记录反馈
-> 主管复盘改进
```

第一版页面不是营销页，也不是泛 CRM。它是销售和主管每天使用的工作台，必须让用户快速知道：

```text
今天该跟谁
为什么要跟
发什么话术
有什么风险
主管该介入哪里
```

## 2. 全局应用框架

### 2.1 桌面端布局

```text
┌──────────────────────────────────────────────────────────────┐
│ TopBar：企业 / 当前角色 / 同步状态 / 全局搜索 / 用户菜单       │
├──────────────┬───────────────────────────────────────────────┤
│ SideNav      │ MainContent                                   │
│              │                                               │
│ 工作台        │ 页面标题 / 筛选 / 主内容 / 右侧抽屉             │
│ 客户          │                                               │
│ 待确认话术     │                                               │
│ 数据接入       │                                               │
│ 复盘中心       │                                               │
│ 设置          │                                               │
└──────────────┴───────────────────────────────────────────────┘
```

SideNav 宽度建议 224px。TopBar 高度建议 56px。主内容区使用 `--color-bg-page`，页面内容使用统一间距 `--space-6`。

### 2.2 移动和窄屏策略

MVP 优先桌面 Web。窄屏下：

- SideNav 折叠为顶部菜单。
- 客户详情的右侧 AI 推荐面板变为底部抽屉或全屏抽屉。
- 表格降级为列表卡片。
- 不牺牲“复制话术”的主操作可见性。

## 3. 导航结构

```text
工作台 Dashboard
客户 Customers
待确认话术 Follow-up Tasks
数据接入 Data Ingestion
复盘中心 Review Center
设置 Settings
```

导航项必须使用统一图标组件。当前页面有 active 状态，不能只靠颜色表达，也要有左侧指示条或背景区分。

## 4. 工作台 Dashboard

### 4.1 页面目标

销售打开后第一眼知道今天最应该处理什么。主管打开后第一眼知道团队最大的机会和风险。

### 4.2 页面结构

```text
┌──────────────────────────────────────────────────────────────┐
│ 页面标题：工作台                                               │
│ 副标题：今天有 12 条待确认话术，3 个高意向客户需要优先跟进       │
├──────────────────────────────────────────────────────────────┤
│ MetricRow                                                     │
│ [待确认话术] [高意向客户] [沉默客户] [流失风险] [今日已复制]    │
├───────────────────────────────┬──────────────────────────────┤
│ 今日待确认话术                 │ AI 今日复盘摘要                │
│ ScriptTaskList                 │ ReviewSummaryPanel            │
│ - 客户 A                       │ - 今日最大机会                 │
│ - 客户 B                       │ - 今日最大风险                 │
│ - 客户 C                       │ - 建议动作                     │
├───────────────────────────────┼──────────────────────────────┤
│ 高意向客户                     │ 需要主管介入                   │
│ CustomerPriorityList           │ ManagerInterventionList        │
└───────────────────────────────┴──────────────────────────────┘
```

### 4.3 核心组件

- `MetricCard`
- `ScriptTaskCard`
- `AgentInsight`
- `AgentRiskFlag`
- `CustomerPriorityList`
- `ManagerInterventionList`
- `ReviewSummaryPanel`

### 4.4 ScriptTaskCard 内容

每张待确认话术卡必须包含：

```text
客户名称
客户阶段 Badge
意向等级 Badge
推荐动作
推荐话术预览
推荐理由
风险提示
主按钮：复制话术
次按钮：换一种 / 跳过 / 标记不准
```

禁止使用“发送”作为主按钮。第一版只能复制。

### 4.5 状态

空状态：

```text
暂无待确认话术
引导：上传聊天记录 / 查看客户列表 / 生成复盘
```

AI 分析中：

```text
正在识别客户阶段
正在生成推荐话术
正在检查风险提示
```

错误状态：

```text
今日任务生成失败，请重试或检查聊天记录是否已导入。
```

## 5. 客户列表 Customers

### 5.1 页面目标

让销售和主管无需进入详情，就能判断客户优先级和风险。

### 5.2 页面结构

```text
┌──────────────────────────────────────────────────────────────┐
│ 页面标题：客户                                                  │
│ 操作：上传聊天记录 / 新增客户 / 同步企业微信                    │
├──────────────────────────────────────────────────────────────┤
│ FilterBar                                                     │
│ 搜索客户 | 阶段 | 意向 | 风险 | 负责人 | 最近沟通时间             │
├──────────────────────────────────────────────────────────────┤
│ CustomerTable                                                 │
│ 客户 | 阶段 | 意向 | 主要顾虑 | 最后沟通 | 待跟进 | 负责人 | 操作 │
└──────────────────────────────────────────────────────────────┘
```

### 5.3 表格列

| 列 | 内容 | 说明 |
| --- | --- | --- |
| 客户 | 昵称、来源、标签摘要 | 昵称为主，来源辅助 |
| 阶段 | `StageBadge` | 使用语义色，不硬编码 |
| 意向 | `IntentBadge` | 高/中/低/风险 |
| 主要顾虑 | 价格、效果、售后等 | 最多展示 2-3 个 |
| 最后沟通 | 时间和相对时间 | 如“2 小时前” |
| 待跟进 | 是否有任务 | 显示任务数量或状态 |
| 负责人 | 销售姓名 | 主管视角必需 |
| 操作 | 查看 / 生成话术 | 操作按钮统一 |

### 5.4 状态

空状态：

```text
还没有客户数据
引导：上传聊天记录 或 配置企业微信
```

筛选无结果：

```text
没有符合条件的客户
操作：清空筛选
```

权限不足：

```text
你没有权限查看该销售的客户，请联系主管或管理员。
```

## 6. 客户详情 Customer Detail

### 6.1 页面目标

展示客户完整上下文，让销售确认 Agent 推荐是否合理。

### 6.2 桌面布局

```text
┌──────────────────────────────────────────────────────────────┐
│ 客户标题区：客户名 / 阶段 / 意向 / 负责人 / 最后沟通时间         │
├──────────────────────────────┬───────────────────────────────┤
│ MainColumn                    │ RightPanel                    │
│                              │                               │
│ 客户资料摘要                  │ CustomerProfileSummary         │
│ 聊天记录 Timeline             │ AgentInsight                   │
│ 历史跟进任务                  │ ScriptRecommendationPanel      │
│ 销售反馈记录                  │ RiskFlags                      │
└──────────────────────────────┴───────────────────────────────┘
```

建议比例：主列 65%，右栏 35%。右栏在滚动时可 sticky，但不能遮挡内容。

### 6.3 客户画像区

展示：

```text
需求点
预算倾向
产品兴趣
主要顾虑
沟通风格
当前阶段
意向等级
推荐策略
```

每个画像字段都应支持“来源说明”或“由最近对话推断”。

### 6.4 聊天记录 Timeline

每条消息显示：

```text
发送人
时间
消息内容
是否被 Agent 引用为判断依据
```

如果某条消息被 Agent 用作理由，可显示轻量标记：

```text
用于判断：价格异议 / 高意向 / 沉默风险
```

### 6.5 右侧 AI 推荐面板

必须包含：

```text
推荐动作
推荐话术
推荐理由
风险提示
下一次建议跟进时间
操作：复制话术 / 换一种 / 标记不准 / 跳过
```

### 6.6 状态

- 客户不存在：返回客户列表。
- 无聊天记录：引导上传该客户聊天记录。
- Agent 分析失败：保留聊天记录，允许重新分析。
- 标记不准：打开反馈弹窗，选择原因并可填写说明。

## 7. 待确认话术 Follow-up Tasks

### 7.1 页面目标

集中处理所有待确认话术，适合销售批量工作。

### 7.2 页面结构

```text
┌──────────────────────────────────────────────────────────────┐
│ 页面标题：待确认话术                                           │
│ Tab：全部 / 高意向 / 风险 / 沉默唤醒 / 已处理                   │
├──────────────────────────────────────────────────────────────┤
│ FilterBar：客户、阶段、意向、话术类型、生成时间                 │
├──────────────────────────────┬───────────────────────────────┤
│ TaskList                     │ TaskDetail                    │
│ - 任务 A                      │ 选中任务的完整话术和理由        │
│ - 任务 B                      │                               │
│ - 任务 C                      │                               │
└──────────────────────────────┴───────────────────────────────┘
```

### 7.3 任务详情

```text
客户资料摘要
最近聊天摘要
推荐话术
推荐理由
风险提示
可替换版本
操作历史
```

### 7.4 操作

- 复制话术：记录采纳。
- 换一种：生成替代版本，保留历史版本。
- 跳过：要求选择跳过原因。
- 标记不准：要求选择不准原因。

## 8. 数据接入 Data Ingestion

### 8.1 页面目标

让用户清楚知道有两条数据进入路径：企业微信接入和上传/粘贴聊天记录。企业微信未配置时，不能阻塞主流程。

### 8.2 页面结构

```text
┌──────────────────────────────────────────────────────────────┐
│ 页面标题：数据接入                                             │
│ 副标题：连接企业微信，或先上传聊天记录体验 Agent                 │
├──────────────────────────────┬───────────────────────────────┤
│ 企业微信接入                  │ 上传/粘贴聊天记录               │
│ WeComIntegrationCard          │ UploadConversationCard         │
│ - 配置状态                    │ - 上传文件                     │
│ - CorpID / Secret             │ - 粘贴文本                     │
│ - 权限检查                    │ - 示例格式                     │
│ - 同步按钮                    │ - 开始解析                     │
└──────────────────────────────┴───────────────────────────────┘
```

### 8.3 上传解析流程

```text
选择文件或粘贴文本
-> 预检查格式
-> 解析发送人、时间、内容
-> 用户确认解析结果
-> Agent 分析客户画像和话术
-> 跳转客户详情或工作台
```

### 8.4 解析结果确认页/弹窗

必须展示：

```text
识别到的客户
识别到的销售
消息数量
时间范围
无法识别的消息数量
可编辑归属
确认导入
```

### 8.5 状态

- 企业微信未配置：展示“先上传聊天记录体验”。
- 企业微信同步失败：展示原因和检查项。
- 上传格式错误：展示支持格式和示例。
- 解析为空：提示检查是否包含时间、发送人和消息内容。

## 9. 复盘中心 Review Center

### 9.1 页面目标

帮助销售和主管知道哪里有机会、哪里有风险、下一步怎么改。

### 9.2 页面结构

```text
┌──────────────────────────────────────────────────────────────┐
│ 页面标题：复盘中心                                             │
│ 时间范围：今日 / 7 天 / 30 天                                  │
├──────────────────────────────────────────────────────────────┤
│ MetricRow                                                     │
│ [高意向] [风险客户] [采纳率] [回复率] [阶段推进]               │
├──────────────────────────────┬───────────────────────────────┤
│ AgentReviewPanel             │ RiskCustomerList               │
│ - 最大机会                    │ - 客户 A                       │
│ - 最大风险                    │ - 客户 B                       │
│ - 改进建议                    │ - 客户 C                       │
├──────────────────────────────┼───────────────────────────────┤
│ ScriptEffectivenessTable      │ StageDistribution              │
│ 话术类型 / 复制率 / 回复率     │ 阶段分布                        │
└──────────────────────────────┴───────────────────────────────┘
```

### 9.3 AgentReviewPanel

每条复盘建议必须包含：

```text
发现的问题
影响范围
证据
建议动作
关联客户或话术
```

示例：

```text
发现：价格异议客户的回复率低于平均水平。
证据：过去 7 天 18 个价格异议客户中，仅 4 个在跟进后回复。
建议：补充价格解释模板和案例证明话术，优先复盘客户 A、客户 B。
```

### 9.4 数据不足状态

不能制造精确假象。样本不足时显示：

```text
当前样本不足，建议先导入更多聊天记录。已有数据可用于生成单客户建议，但不适合做团队趋势判断。
```

## 10. 设置 Settings

### 10.1 MVP 范围

设置页只做必要能力：

```text
个人信息
角色信息
企业微信配置入口
AI 分析偏好
数据安全说明
```

不做复杂组织架构和商业化配置。

### 10.2 AI 分析偏好

可预留：

```text
话术风格：专业 / 亲切 / 简洁
风险敏感度：标准 / 严格
默认跟进提醒时间
```

## 11. 登录页

### 11.1 页面目标

清晰、可信、低干扰。登录页不做营销大页。

### 11.2 结构

```text
左侧：产品名、定位、可信说明
右侧：登录表单
```

文案：

```text
企灵 Agent
企业微信私域销售自动跟进与复盘智能体
```

登录方式 MVP 可先支持账号密码，后续扩展企业微信扫码。

## 13. 关键交互说明

### 13.1 复制话术

```text
点击复制话术
-> 写入剪贴板
-> Toast：已复制，可粘贴到企业微信发送
-> 任务状态变为已复制
-> 记录反馈事件
```

失败：

```text
复制失败，请手动选择话术内容复制。
```

### 13.2 换一种

```text
点击换一种
-> 保留当前话术
-> 请求生成替代版本
-> 展示新版本
-> 可切回历史版本
```

### 13.3 标记不准

弹窗字段：

```text
阶段判断不准
意向判断不准
话术不自然
没有结合上下文
风险提示缺失
其他说明
```

### 13.4 跳过

必须记录原因：

```text
客户暂不适合跟进
销售已线下处理
话术不适合
重复任务
其他
```

## 14. 后续实现注意事项

前端实现前必须先创建：

```text
src/styles/tokens.css
src/styles/base.css
src/styles/layout.css
src/styles/components.css
src/styles/states.css
src/styles/themes.css
```

页面实现顺序建议：

```text
1. AppShell
2. 基础 UI 组件
3. 业务 Badge 和 Agent 组件
4. 数据接入页
5. 客户详情页
6. 工作台
7. 客户列表
8. 待确认话术
9. 复盘中心
10. 设置和登录
```

原因：MVP 演示主链路依赖数据接入和客户详情，先做这两个页面能最快验证“上传聊天记录 -> Agent 分析 -> 复制话术”。
