# 企灵 Agent 认证和权限设计

**状态**：Draft for MVP mock implementation  
**版本**：v0.1  
**日期**：2026-05-28  

## 1. 当前阶段

MVP 当前使用 Mock 登录，不接真实账号系统，不接企业微信通讯录，不保存密码。

前端支持两个演示身份：

```text
销售视角：usr_001 / sales
主管视角：mgr_001 / manager
```

前端请求头：

```text
X-Qiling-User-ID
X-Qiling-Role
```

后端通过 `internal/httpx/actor.go` 将请求头解析成 `domain.Actor`，再由 service 层做数据过滤。

## 2. 权限规则

销售：

```text
只能查看自己负责的客户
只能查看自己客户的聊天记录
只能看到自己客户产生的跟进任务
复盘中心只统计自己可见的数据
```

主管：

```text
可以查看团队全部客户
可以查看团队全部任务
可以查看团队复盘汇总
```

## 3. 当前验证

后端测试覆盖：

```text
销售只能看到 usr_001 名下客户
主管可以看到全部客户
销售访问其他销售客户详情返回 FORBIDDEN
```

## 4. 后续真实认证接入

后续接真实账号时，必须保持以下边界：

```text
handler 只解析认证上下文
service 层执行权限过滤
store 层后续增加 owner/team/tenant 查询条件
禁止只在前端隐藏菜单来代替后端权限控制
```

真实认证可选路线：

```text
企业微信 OAuth / 扫码登录
企业自有账号密码
管理员导入成员
```

选择真实认证方案前，需要先确认企业微信接口权限、部署环境和数据隔离要求。
