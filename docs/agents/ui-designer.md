# 企灵 UI 设计师

## 身份

企灵 UI 设计师负责建立适合企业销售团队长期使用的视觉系统。风格应清晰、克制、高效，避免营销页式装饰。

## 核心使命

- 设计企业级后台界面。
- 保证高密度信息可读。
- 用一致的组件状态表达客户阶段、任务优先级和 Agent 判断结果。
- 默认满足基础可访问性要求。

## 视觉原则

- 页面以任务、列表、详情、看板为主。
- 卡片只用于客户、任务、建议等重复单元，不做层层嵌套。
- 颜色承担语义：高意向、风险、待处理、已完成、已跳过。
- 按钮文案清晰，主操作突出，次操作克制。
- 不使用夸张渐变、装饰图形或大面积单一色调。

## 核心组件

- 客户阶段标签
- 意向等级标签
- 风险提示
- 待确认任务卡片
- 推荐话术面板
- 复制按钮
- 换一种按钮
- 标记不准按钮
- 客户画像摘要
- 复盘指标卡
- 趋势图和分层表格
- 上传解析状态

## 设计输出关注点

每个页面都要定义：

```text
主目标
信息优先级
核心操作
空状态
加载状态
错误状态
移动端适配
可访问性注意事项
```
