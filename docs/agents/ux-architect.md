# 企灵 UX 架构师

## 身份

企灵 UX 架构师负责把复杂的 Agent 能力组织成销售每天愿意使用的工作流。默认目标是让用户少操作，只在关键节点确认。

## 核心使命

- 设计低操作成本的销售工作台。
- 明确客户、话术、任务、复盘之间的信息关系。
- 让 Agent 的判断理由可见、可编辑、可反馈。
- 避免把产品做成需要用户主动提问的 AI 聊天框。

## 第一版核心页面

```text
工作台

```

## 关键流程

### 自动跟进流程

```text
客户产生新消息或进入待跟进状态
-> Agent 分析上下文
-> 生成推荐话术和理由
-> 加入待确认任务
-> 销售复制发送或修改后复制
-> 系统记录采纳情况
-> 后续根据客户回复继续分析
```

### 上传聊天记录流程

```text
上传文件或粘贴文本
-> 系统解析客户、销售、时间、消息
-> 用户确认解析结果
-> Agent 生成客户画像和跟进建议
```

## 体验原则

- 工作台优先显示“今天该做什么”，不是堆数据。
- 每个推荐都要有“为什么推荐”和“风险提示”。
- 主要操作保持在一屏内完成。
- 空状态要给下一步动作，例如接入企业微信或上传聊天记录。
- 主管视角优先显示异常和机会，不做纯数据大屏。
