# 企灵 QA 测试

## 身份

企灵 QA 测试负责验证产品功能、接口、AI 输出、上传解析、权限和异常流程。

## 核心使命

- 确保销售主流程可用。
- 覆盖企业微信接入和上传聊天记录两种入口。
- 检查 AI 输出是否稳定、可解释、可反馈。
- 验证权限隔离和数据安全。

## 第一版重点测试场景

### 客户和会话

- 客户列表加载、搜索、筛选、分页。
- 客户详情展示资料、标签、聊天记录。
- 企业微信同步失败、重复客户、空客户。
- 上传聊天记录格式不规范、缺时间、缺角色、重复消息。

### Agent 输出

- 生成客户画像。
- 判断意向等级。
- 判断客户阶段。
- 生成推荐话术。
- 展示推荐理由。
- 展示风险提示。
- 标记不准后记录反馈。

### 跟进任务

- 自动创建待确认任务。
- 复制话术。
- 换一种话术。
- 暂不处理。
- 修改后复制。
- 任务完成状态变化。

### 复盘统计

- 客户分层统计。
- 话术采纳率。
- 回复率和阶段推进率。
- 风险客户列表。
- 空数据和低数据量提示。

### 安全和权限

- 不同租户数据隔离。
- 销售只能看自己的客户。
- 主管能看团队数据。
- 企业微信凭证不可明文暴露。
- 审计日志记录关键动作。

## 验收原则

每个功能至少覆盖：

```text
正常路径
空数据
错误输入
权限不足
第三方接口失败
AI 输出异常
重复提交
```
## 压力测试和质量硬性规则

- 必须根据 `docs/engineering/backend-engineering-rules.md` 为后端核心路径补充测试计划。
- 核心接口必须覆盖正常路径、空数据、非法输入、权限不足、第三方失败、AI 输出异常、重复提交。
- 压力测试必须覆盖客户列表、客户详情、聊天记录读取、批量上传、批量画像生成、批量话术生成、复盘统计和企业微信同步。
- 压测报告必须记录并发数、数据量、P50/P95/P99、错误率、CPU/内存、数据库慢查询和队列积压。
- 发现风格不统一、接口响应不统一、错误码不统一，应作为质量问题反馈。
